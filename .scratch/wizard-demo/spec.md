# Wizard 求职 Demo 规格草案

状态：待整体审阅。下列“已确认”来自需求访谈；“技术提案”和“待素材验证”不代表已经获得确认。

整理日期：2026-10-27。交付截止：2026-11-03。

## 1. 目标与边界

- Windows 单机、俯视角、法师主题，用于求职展示。
- 优先级：代码质量和框架使用正确性，高于功能数量及美术复杂度。
- 核心业务使用 C++；蓝图和资产用于数据、资源引用、动画表现和 UI 布局。
- 必须使用 GAS、CommonUI 和 Enhanced Input。
- 英文标识符；中文注释、项目说明和文档。中文注释是相对 Epic 英文要求的明确项目例外。
- Codex 承担主要 C++ 编写、解释设计理由、建立验证与学习机制；用户参与资产配置、验收和学习。
- 每天投入至少约四小时，包含弹性的学习与测试时间；这不是工期保证。
- 学习资料、练习、个人测验、答案和掌握度记录放在 `/.local-learning/`，由 Git 忽略。
- 工程自动化测试、规格、架构说明、验证记录纳入项目版本控制。

## 2. 已确认的游戏循环

单张固定小地图，包含安全营地与战斗区域；商店位于营地。

营地配置技能、购买装备 → 交互开始挑战 → 清理三波预设敌人 → 自动拾取金币、物品和素材 → 结算并返回营地 → 出售战利品、调整装备 → 再次挑战。

- 敌人至少包括近战追击和远程投射物攻击两种行为。
- 再次开始挑战时重置战斗区域。
- 死亡后返回营地，恢复生命、法力，保留金币、背包、装备及技能搭配；本轮战斗重置。
- 最终敌人、手柄支持、演示录屏为加分项。防具外观替换不作要求。
- 随机地图、合成、强化、随机词条、耐久、回购、商店刷新和复杂成长不在基础交付范围。

## 3. 输入与界面

| 编号 | 已确认要求 |
| --- | --- |
| R01 | WASD 移动，鼠标指向瞄准；普通攻击使用鼠标左键，1234 释放四槽技能 |
| R02 | 左键单击发射一次普通远程攻击，长按连续攻击；不消耗法力，不占四个技能槽，攻击间隔由数据配置 |
| R03 | 背包、技能搭配、商店界面打开时暂停世界；关闭后恢复；Esc 依次关闭最上层界面 |
| R04 | UI 操作不触发世界中的攻击、技能或移动；连续攻击在界面切换后的状态必须可验证 |

背包、技能界面及交互的具体快捷键尚未确认。技术提案：B 打开背包、K 打开技能、E 交互，全部配置在输入资产中。

## 4. GAS 与技能

| 编号 | 已确认要求 |
| --- | --- |
| R05 | 至少六个候选主动技能，玩家携带其中四个；全部开局解锁 |
| R06 | 仅在营地调整技能搭配；同一技能不可重复装备 |
| R07 | 核心能力行为使用 C++；数据配置技能的数值、消耗、冷却、资源引用和表现 |
| R08 | 普通攻击及技能正确使用 GAS 的授予、激活、提交、结束和取消流程 |

候选机制如下，具体效果素材需要在编辑器中预览后确定。允许根据素材提出替代方案；改变技能机制时更新本规格并说明变更。

| 候选 | 行为目标 | 素材状态 |
| --- | --- | --- |
| 火球 | 投射物单体伤害 | 已找到投射物、火焰候选；待预览 |
| 冰箭 | 投射物伤害与短暂减速 | 已找到冰拖尾候选；待预览 |
| 雷击 | 鼠标落点范围伤害 | 已找到闪电、范围效果候选；待预览 |
| 闪现 | 有距离限制的位移，检查有效落点 | 位移逻辑不依赖专用动画；表现待验证 |
| 护盾 | 限时且有吸收量的护盾 | 光环或增益特效候选；待验证 |
| 治疗 | 即时恢复自身生命 | 已找到治疗特效候选；待预览 |

基础属性：当前/最大生命、当前/最大法力、攻击力、防御力、移动速度；保留护盾技能时加入护盾量。

伤害使用一套明确、可测试的计算规则；具体公式及数值属于待审阅的平衡提案。最大生命变化时保留当前生命并限制到新上限，反复穿脱装备不能产生免费治疗。

| 编号 | 已确认要求 |

## 9. 数据驱动的验收定义

在已有行为类型内，新增技能、装备、药水、出售素材、商店商品或掉落条目，通过配置定义与资源引用完成，不修改已有业务分支。

增加此前没有的机制允许扩展 C++，再通过数据配置复用。具体采用 Data Asset、Data Table、Curve 或 GameplayEffect 的方式是工程设计选择，不要求所有配置都采用同一种资产。

必须演示：新增一件装备后进入商店和掉落表，完成拾取、装备、属性反馈、出售及存档往返；新增一种出售素材后完成掉落、图标显示、堆叠和出售。
