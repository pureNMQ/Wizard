# T05 图标掉落与自动拾取

- Status: ready
- Blocked by: [T02](./02-basic-combat.md)、[T04](./04-inventory-and-items.md)
- Spec: R10、R15、R16、R17、R18、R19，正文见 [规格](../spec.md)
- Updated: 2026-10-28

## 目标与范围

将敌人死亡和物品事务接为金币、装备、药水、出售素材的配置掉落，完成带图标的地面物品、自动拾取及主动丢弃。

## 输入、输出与不变量

- 输入：一次性死亡事件、掉落配置、玩家接近/离开、丢弃数量。
- 输出：金币余额或背包变更、地面剩余数量与实际物品图标。
- 拾取与丢弃使用完整事务，失败不丢物品；金币不占格，死亡掉落只处理一次。

## 失败与边界

覆盖背包满、只能部分接收、重复接触、错误定义/图标、掉落生成失败及主动丢弃后仍处范围内。完全无法接收时地面对象保持有效。

## 验收条件

- [ ] 四类掉落来自配置，地面对象引用实际定义并显示对应图标。
- [ ] 范围内自动拾取；部分接收后数量准确留在地面；金币直接入账。
- [ ] 丢弃数量准确扣减并生成对象，失败保持来源状态。
- [ ] 丢弃者离开范围再进入后才恢复自动拾取。
- [ ] 死亡/拾取重复事件、物品守恒、真实图标和独立包加载有证据。
