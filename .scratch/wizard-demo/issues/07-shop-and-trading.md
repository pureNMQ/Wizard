# T07 商店与出售素材

## 目标与范围

在营地预留位置接入商店交互，复用物品定义和事务完成购买、出售与素材堆叠出售，首版库存无限。

## 输入、输出与不变量

- 输入：商品/定义、买卖方向、数量、金币与背包状态。
- 输出：可区分的交易结果及一次提交后的余额和物品状态。
- 金币唯一货币，价格/目录来自配置，库存规则按规格；装备中的物品先卸下再售。

## 失败与边界

验证金币不足、容量不足、错误定义/价格/数量、数量乘价范围溢出、不可交易物品及重复请求。任意失败均不扣金币、不改变物品。

## 验收条件

- [ ] 营地交互打开真实 CommonUI 商店，四类装备和两类药水均可购买。
- [ ] 购买、出售通过数量选择与明确按钮提交，价格/目录为配置。
- [ ] 背包内可交易装备、药水和素材可售，装备中物品不可直接售。
- [ ] 暂停中交易/返回可用，界面刷新读实际业务状态。
- [ ] 失败交易、数量/金币一致性与新增商品/素材配置有验证。
