## 目标与范围

现有背包、商店、炼金台、HUD、详情、数量弹窗统一为深墨蓝底、暖白文字、旧金主操作及奥术蓝选中状态。调整字号、留白、图标容器和详情层级；不增加页面、教学文案或玩法。

## 输入、输出与不变量

显示现有业务状态；保留20格、四装备槽、六列技能候选、四技能槽、暂停/返回、数量整数同步与交易规则。保留用户地图与正在进行的存档工作。

## 失败与边界

长物品描述、五条装备属性、空槽、缺蓝/冷却、悬浮窗按钮、缩放下文字裁切与按钮遮挡。视觉布局由Widget配置，C++仅刷新数据和状态；不新增一次性桥接。

## 验收条件

- [x] 现有Widget颜色、字体、按钮与状态样式一致，编辑态编译/绑定检查通过。
- [ ] 属性标签/数值对齐，详情名称与正文分层，HUD冷却进度及文字同步。
- [x] 受影响C++通过UHT/UBT与必要既有检查。

### 2026-11-02 第二轮：统一三个主页面

用户反馈第一轮总体观感不错，但炼金台过矮、候选区只有一行、仅商店有关闭按钮，要求继续统一三个页面。本轮以以下固定规则替代上轮分散的页面尺寸：

| 元素 | 统一规则 |
| --- | --- |
| 主窗口 | 1040×652，中心锚点/中心对齐；同一背景、描边、圆角 |
| 标题 | 面板内(28,18)，300×38，28号粗体；名称不变 |
| 关闭 | 面板内(976,18)，36×36，同一按钮样式和20号×；内边距一致 |
| 标题分隔线 | (28,70)，984×1 |
| 内容区 | 左右28，顶部88；同一弱分隔线，不追加教学文案 |
| 底部 | 分隔线y606，反馈(28,620)，984×22 |
| 背包与商店物品格 | 统一88×88，格间每侧4；5列4行480×384 |
| 金币 | 背包与商店都放标题栏右侧，图标/数值同色同字号 |

炼金台候选框984×368，内部720宽的六列列表居中，至少保留两整行的展示空间；四个已装备槽保留在下方独立区域。没有新增实际技能或占位技能。背包保留属性左、装备中、背包右；商品详情、购买入口及商店双栏继续保留。

关闭按钮在NativeConstruct使用AddUniqueDynamic，NativeDestruct解除；鼠标关闭和Esc均调用现有DeactivateWidget流程，清理/暂停协调继续交由原有CommonUI生命周期。没有新增输入映射或世界输入调用。
