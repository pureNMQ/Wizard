# T06 拖拽装备与加成

- Status: ready

- Spec: R11、R12、R20、R21、R22、R28，正文见 [规格](../spec.md)
- Updated: 2026-10-28

## 目标与范围

完成帽子、衣服、靴子、法杖四槽装备，接通跨背包/装备拖拽、属性加成和法杖显示。读档与重生的重建接口为后续任务保留。

## 输入、输出与不变量

- 输入：稳定物品身份、目标槽、装备配置与当前背包容量。
- 输出：一次性换装结果、装备/背包状态、GE 加成 Handle 与表现。
- 任一实例只有一个归属；加成准确施加和移除。最大生命变化保留当前值并夹到新上限，穿脱不能免费治疗。

## 失败与边界

检查错误槽位、不存在实例、背包满时卸下/替换、无效拖拽、反复换装、清理/重建与最大生命降低。

## 验收条件

- [ ] 四槽与每槽至少两件固定属性配置成立，允许所支持属性的数据加成。
- [ ] 拖拽装备、替换、卸下遵守事务与容量规则，取消/失败不改变归属。
- [ ] GE Handle 明确管理，反复操作没有重复或遗留加成。
- [ ] 生命夹取规则有自动化验证，法杖挂接与 UI 数值在运行中正确。
- [ ] 读档/重生可统一重建有效加成，完整往返由 T08/T09 集成验证。
